# 数据与示例 / Data and examples

`examples/data/`包含由`examples/synthetic_demo.py`生成的合成水网输入，供快速运行和接口演示。运行脚本可重新生成这些文件。

研究案例通过`--data-dir`提供各自的网络、气象、需水、工程与参数文件。字段、单位及缓存规则见[数据接口](docs/DATA_INTERFACE.md)。

The example dataset is synthetic and generated by `examples/synthetic_demo.py`. Case-specific research data are supplied through `--data-dir`; see the data-interface documentation for schemas and units.
